# ⚡ 5 MINUTOS - Guía de Inicio Rápido

## 🚀 Comienza en 5 Minutos

### Paso 1: Abre Terminal (30 segundos)
```bash
cd /home/axel-michael/Documentos/guia_estudio/english-learning-platform
```

### Paso 2: Inicia Aplicación (10 segundos)
```bash
source .venv/bin/activate
python app.py
```

Verás algo como:
```
* Running on http://127.0.0.1:5000
```

### Paso 3: Abre Navegador (20 segundos)
```
http://127.0.0.1:5000
```

### Paso 4: Crea Cuenta (2 minutos)
- Click "Register"
- Ingresa:
  - Name: Tu nombre
  - Email: tu@email.com
  - Password: contraseña
  - Confirm: misma contraseña
- Click "Create Account"

### Paso 5: Explora (2 minutos)
- Click "Login"
- Ingresa tu email y contraseña
- Ves 6 unidades
- Click en "Unit 7: MIND"
- Explora vocabulario, gramática, ejercicios

## 🆘 Problema?

**Port 5000 en uso?**
```bash
# Usa otro puerto
FLASK_ENV=development FLASK_APP=app.py flask run --port 5001
# Accede a http://localhost:5001
```

**No ve los datos?**
```bash
# Re-popula base de datos
python seed_db_extended.py
# Recarga página (Ctrl+Shift+R)
```
