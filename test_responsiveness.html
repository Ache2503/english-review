📐 Tipografía Fluida

Utiliza función CSS clamp() para escalado automático de fuentes sin media queries.

  • h1: clamp(1.75rem, 5vw, 2.5rem)
  • h2: clamp(1.5rem, 4vw, 2rem)
  • h3: clamp(1.25rem, 3vw, 1.5rem)
  • Body: Font-size responsive

📏 Espaciado Fluido

Padding, margin y gap adaptables con clamp() para todos los tamaños.

  • padding: clamp(1rem, 3vw, 2rem)
  • margin: clamp(1rem, 2vw, 1.5rem)
  • gap: 0.5rem - 2rem
  • Container: Dinámico

👆 Touch Optimized

Diseño amigable para dispositivos touch con botones de 44px mínimo.

  • Button min-height: 44px
  • Touch targets: 44x44px
  • Tap feedback visual
  • Spacing para thumbs

🍔 Navbar Responsive

Navegación que se adapta a todos los tamaños con hamburger menu en móvil.

  • Dropdowns adaptables

🖼️ Imágenes Responsive
