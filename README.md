# English Review - B1 Level

A comprehensive English B1 (Intermediate) level review project for self-study and practice.

## About B1 Level

The B1 level (Threshold or Intermediate) according to the Common European Framework of Reference for Languages (CEFR) means you can:
- Understand the main points of clear standard input on familiar matters
- Deal with most situations likely to arise while travelling
- Produce simple connected text on topics which are familiar
- Describe experiences, events, dreams, hopes and ambitions

## Project Structure

```
english-review/
├── grammar/          # Grammar exercises and explanations
├── vocabulary/       # Vocabulary lists and exercises
├── reading/          # Reading comprehension exercises
├── writing/          # Writing prompts and guidelines
├── listening/        # Listening practice resources
└── speaking/         # Speaking topics and conversation practice
```

## How to Use This Project

1. **Start with Grammar**: Review the grammar topics in the `grammar/` folder
2. **Build Vocabulary**: Practice with vocabulary lists in the `vocabulary/` folder
3. **Practice Skills**: Work through reading, writing, listening, and speaking exercises
4. **Track Progress**: Mark exercises as completed and review regularly

## B1 Level Topics Covered

### Grammar
- Present, past, and future tenses
- Present perfect vs past simple
- Conditional sentences (type 1 and 2)
- Passive voice
- Modal verbs
- Reported speech
- Relative clauses

### Vocabulary Areas
- Daily routines and activities
- Travel and tourism
- Work and education
- Health and fitness
- Technology and media
- Environment and nature

## Getting Started

Choose a topic from any folder and start practicing. Each section includes:
- Explanations and examples
- Practice exercises
- Answer keys for self-correction
